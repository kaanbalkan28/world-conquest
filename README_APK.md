World Conquest - Android APK hazırlık paketi

Bu paket, yüklediğiniz world_conquest_vaa.zip içindeki oyun dosyalarını Capacitor Android uygulaması için www/ klasörüne yerleştirir.

Windows'ta APK derlemek için:
1. Node.js LTS ve Android Studio kurun. Android Studio'dan Android SDK Platform ve Build Tools bileşenlerini kurun.
2. Bu klasörde setup_android_windows.bat dosyasını çalıştırın.
3. İşlem başarılı olunca build_debug_apk.bat dosyasını çalıştırın.
4. Oluşan APK: android\app\build\outputs\apk\debug\app-debug.apk

Not: Bu ZIP bir APK dosyası değildir. Bu çalışma ortamında Android SDK/Gradle kurulu olmadığından gerçek APK burada derlenemedi.
